Subject: Hobby plan eligibility question - free mobile game backend

Hi Vercel team,

I run a personal Hobby account and would like a written confirmation before I
deploy something that might fall outside the plan's terms.

The project: a small daily word-puzzle game for Android. The deployment would
be a Next.js API backend the app talks to (fetch the daily puzzle, submit a
guess, return the score). Traffic would be modest: one puzzle per player per
day plus a handful of API calls per session.

The exact usage facts:
- The app is completely free on Google Play.
- It has no advertising of any kind.
- It has no in-app purchases or paid features.
- The project is supported by voluntary tips/donations from users
  (a tip link, nothing required to play).
- I am an individual developer, not a company; this is my own personal project.

Section 4 of your Terms of Service limits the Hobby plan to personal or
non-commercial use. Given the facts above, especially the voluntary tips,
does this deployment qualify for the Hobby plan? If it does not, which plan
would you say fits a project of this size?

A short written answer either way is all I need. Thank you.

---

## Why it is worded this way
- States free/no-ads/no-IAP exactly, and presents tips as voluntary donations
  rather than claiming "no revenue" - tips are a form of support and hiding
  them would make any yes answer worthless.
- Asks a binary eligibility question plus a fallback recommendation, so the
  answer settles the free path either way.
- Nothing here commits to a deployment, a plan, or a purchase.
